# kitty

Kitty terminal config. Deploys to `~/.config/kitty`.

## Dependencies

| Tool | Needed for | Required? |
|------|------------|-----------|
| `kitty` | the terminal | yes |
| JetBrainsMono Nerd Font | `font_family` | yes |

## Install

```bash
sudo pacman -S --needed kitty ttf-jetbrains-mono-nerd
```
