# swappy

Swappy screenshot editor config. Deploys to `~/.config/swappy`.

## Dependencies

| Tool | Needed for | Required? |
|------|------------|-----------|
| `swappy` | the editor | yes |
| `hyprshot` | piping screenshots in (the Hyprland binds) | yes |

## After `stow swappy`

- Saves go to `~/Downloads`. Create it if it doesn't exist (`mkdir -p ~/Downloads`).
