# opencode

OpenCode config. Deploys to `~/.config/opencode`.

## Dependencies

| Tool | Needed for | Required? |
|------|------------|-----------|
| `opencode` | the agent | yes |
| `git` | installing Superpowers | optional |

## After `stow opencode`

- Optionally install the Superpowers skills. The steps are in
  [`.config/opencode/README.md`](.config/opencode/README.md), or run
  `bash ~/.config/opencode/scripts/install-superpowers.sh`.
